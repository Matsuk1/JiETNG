## 为什么选择 JiETNG？

JiETNG 是同时支持 『maimai でらっくす』 日服和国际服的查分机器人，为休闲玩家和硬核竞技者都提供强大功能。

## 快速开始

只需三个简单步骤即可开始使用 JiETNG：

1. **添加机器人** - 将 JiETNG 添加到您的 LINE 账号
2. **绑定账号** - 安全地关联您的 SEGA ID
3. **开始追踪** - 使用 `maimai update` 同步您的成绩
