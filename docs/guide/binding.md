# 账号绑定

了解如何将您的 SEGA ID 绑定到 JiETNG，以访问您的 『maimai でらっくす』 成绩和记录。

## 绑定机制

JiETNG 使用**基于 Web 的绑定**方式，采用安全的限时令牌。您的凭据通过安全的 Web 表单提交，而不是在聊天中输入。

:::warning 重要
没有命令行绑定方式。您不能在聊天中直接输入您的凭据。所有绑定都通过安全的 Web 界面完成。
:::

## 绑定账号

### 步骤 1: 开始绑定流程

向机器人发送以下命令：

```
bind
```

### 步骤 2: 打开绑定 URL

机器人将发送一个带有唯一 URL 的按钮，点击此按钮。

:::tip 令牌过期
绑定令牌将在 **2 分钟后**过期。如果过期，只需再次发送 `bind` 命令获取新令牌。
:::

### 步骤 3: 输入您的凭据

Web 表单将要求您输入：

- **语言**: 选择您偏好的语言
- **SEGA ID**: 您的 SEGA 账户用户名
- **密码**: 您的 SEGA 账户密码
- **版本**: 选择 `jp`（日本）或 `intl`（国际版）

:::danger 安全提示
- 永远不要与任何人分享您的 SEGA 凭据
- 机器人不会以明文存储您的密码
- 只使用机器人提供的官方绑定 URL
:::

### 步骤 4: 确认

绑定成功后，页面将立即显示成功提示。成绩数据将在后台自动同步，完成后 Bot 会通过 LINE 消息通知您。

:::tip 后台更新
首次绑定的成绩同步（`maimai update`）在后台进行，通常在数秒内完成。您无需等待，可以直接关闭页面。
:::

## 检查绑定状态

验证您的账号是否已绑定：

```
profile
getme
```

这将显示您当前的绑定信息，包括：
- SEGA ID
- 版本（jp/intl）
- 语言设置
- 个人信息状态

## 修改账户设置（rebind）

无需解绑，即可更新密码、时区、语言或 Aime 设置：

```
settings
rebind
```

Bot 将发送一个 Web 链接，表单中已预填您当前的信息（SEGA ID 无法更改）。提交后会立即收到更新确认。

## 解除绑定

从机器人中移除您的 SEGA ID：

```
unbind
```

:::warning 数据删除
解除绑定将**永久删除**您所有存储的数据，包括：
- SEGA 凭据
- 成绩记录
- 好友列表
- 个人信息
- 语言偏好

此操作无法撤销。
:::

## 版本选择

### 日本（jp）

如果您在日本的街机上玩：
- 日本官方 『maimai でらっくす』
- 标准和 DX 谱面
- 所有日本独占歌曲
- URL: https://maimaidx.jp/maimai-mobile/

### 国际版（intl）

如果您在日本以外地区玩：
- 其他国家的 『maimai でらっくす』 机台
- 相比 JP 版本歌曲更新可能会延迟
- 不同地区活动
- URL: https://maimaidx-eng.com/maimai-mobile/

:::tip 选择正确的版本
选择与您实际游玩 『maimai でらっくす』 的地点匹配的版本。之后可通过 `settings` 命令修改版本，无需解绑。
:::

## 成绩更新

绑定后，您可以手动更新成绩：

```
maimai update
```

这将从 maimai NET 获取您的最新成绩并更新机器人中的记录。

:::tip 更新频率
成绩更新会排队并按顺序处理，以避免SEGA服务器过载。在高峰时段，您的更新可能需要几分钟才能完成。
:::
