# 楽曲検索とレコード照会

## 楽曲情報検索

```
[楽曲名] info
[楽曲名] song-info
[楽曲名] ってどんな曲
```

あいまいマッチング（類似度しきい値 85%）、最大 6 曲を返します。大文字小文字を区別せず、特殊記号は省略可能。

**表示内容：** 楽曲タイトル（英語/日本語）、カバーアート、アーティスト、バージョン、利用可能な難易度、譜面定数、譜面タイプ（Standard / DX）、ジャンル。

---

## バージョン別楽曲一覧

```
[バージョン名] version
[バージョン名] version-list
[バージョン名] のバージョンリスト
```

`FESTiVAL+` は自動的に `FESTiVAL PLUS` として認識されます。

---

## アーティスト検索

```
artist [キーワード]
artist [キーワード] [ページ]
```

**表示内容：** 楽曲タイトル、アーティスト名、譜面タイプ（DX / STD / UTAGE）

:::warning 個人チャット専用
:::

---

## 譜面デザイナー検索

```
designer [キーワード]
designer [キーワード] [ページ]
```

**表示内容：** 楽曲タイトル、マッチした譜面デザイナー名と難易度ラベル（例：`Jack [EXP]`）、譜面タイプ（DX / STD / UTAGE）

:::warning 個人チャット専用
:::

---

## 単曲スコア照会

```
[楽曲名] record
[楽曲名] song-record
[楽曲名] のレコード
```

**表示内容：** 達成率、DX スコア、コンボステータス（FC/FC+/AP/AP+）、シンクステータス（FS/FS+/FDX/FDX+）、レーティング貢献値。

---

## レベル別スコア一覧

```
[レベル] record-list
[レベル] records
[レベル] のレコードリスト
[レベル] record-list [ページ]
```

- 整数（例：`14`）は 14.0~14.5 にマッチ、`14+` は 14.6~14.9、小数（例：`14.7`）は精確一致
- 1 ページあたり最大 50 曲（旧バージョン 35 曲 + 新バージョン 15 曲）
