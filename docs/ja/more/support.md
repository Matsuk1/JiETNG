# サポート

## よくある確認

### 成績が更新されない

- SEGA ユーザー：`maimai update` を送信します。
- Import Token ユーザー：ブックマークレットを再度開いてアップロードします。
- クエリコマンドだけでは公式データを再同期しません。

### 連携できない

- 個別チャットで `bind` を使ってください。
- サーバー `jp` / `intl` が正しいか確認してください。
- ブックマークレットだけ使う場合は Import Token モードを選べます。

### ブックマークレットが失敗する

- 公式 maimai モバイルページで実行してください。
  - `https://maimaidx.jp/maimai-mobile/home/`
  - `https://maimaidx-eng.com/maimai-mobile/home/`
- ブラウザでログイン済みか確認してください。
- 画像生成は 15 秒でタイムアウトします。
- アップロード時は Import Token が撤回されていないか確認してください。

### メンション検索が失敗する

対象ユーザーが JiETNG に登録済みで成績データを持っている必要があります。存在しない対象は自分のデータにフォールバックしません。

## 報告時に含めるもの

コマンド、JP/INTL、SEGA 連携か Import Token か、スクリーンショットまたは返信文、発生時刻を含めてください。

SEGA パスワード、Import Token、開発者 Token は公開しないでください。
