# クイックスタート

## 前提条件

- LINE アカウント
- SEGA ID アカウント（maimai NET 用）
- maimai NET へのアクセス権限

## ステップ 1: ボットを追加

LINE で **@299bylay** を検索するか、リンクを使用：[@299bylay](https://line.me/R/ti/p/@299bylay)

## ステップ 2: SEGA ID を連携

プライベートチャットで送信：

```
bind
```

ボットが送信するボタンをクリックして連携ページを開き、SEGA ID、パスワード、サーバーバージョン（`jp` または `intl`）、言語を入力して送信すると連携完了です。

:::warning
連携トークンは 2 分後に期限切れになります。`bind` を再送信すると新しいリンクを取得できます。
:::

## ステップ 3: スコアを更新

```
maimai update
```

## ステップ 4: Best 50 を生成

```
b50
```

その他のコマンドは[コマンド一覧](/ja/commands/)を参照してください。

---

## アカウント管理

### 連携状態の確認

```
profile
getme
```

### アカウント設定の変更

連携を解除せずにパスワード・タイムゾーン・言語などを更新：

```
settings
rebind
```

### 連携の解除

```
unbind
```

:::warning データの削除
連携を解除すると、スコアレコード、フレンドリスト、アカウント情報を含むすべての保存データが**永久に削除**されます。この操作は元に戻せません。
:::

### バージョンの選択

実際にプレイする場所に合ったバージョンを選択してください：

- **jp**（日本）：日本国内のアーケード筐体でプレイ
- **intl**（海外版）：日本国外でプレイ

後から `settings` コマンドで連携を解除せずにバージョンを変更できます。

## JiETNG について

JiETNG は LINE 上で動作する『maimai でらっくす』スコア管理ボットです。公式 SEGA ウェブサイトから直接プレイデータを取得してスコアチャートを生成し、Best 50、レベル別分析、プレート進捗追跡などに対応しています。日本版（jp）と海外版（intl）の両方に対応しています。
