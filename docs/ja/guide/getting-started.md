# クイックスタート

## 前提条件

- LINE アカウント
- SEGA ID アカウント（maimai NET 用）
- maimai NET へのアクセス権限

## ステップ 1: ボットを追加

LINE で **@299bylay** を検索するか、リンクを使用：[@299bylay](https://line.me/R/ti/p/@299bylay)

## ステップ 2: SEGA ID を連携

プライベートチャットで連携コマンドを送信：

```
bind
```

ボットが送信するボタンをクリックして連携ページを開き、SEGA ID、パスワード、サーバーバージョン（JP または International）、言語を入力します。

:::warning
連携トークンは 2 分後に期限切れになります。`bind` を再送信すると新しいリンクを取得できます。
:::

連携が成功したか確認：

```
profile
```

## ステップ 3: スコアを更新

```
maimai update
```

## ステップ 4: Best 50 を生成

```
b50
```

その他のチャートタイプは[スコアコマンド](/ja/commands/record)を参照してください。
