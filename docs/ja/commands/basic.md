# 基本コマンド

このページでは、JiETNG を使用する際に頻繁に使用する基本的なコマンドをすべて紹介します。

## アカウント管理

### SEGA アカウントを連携

SEGA ID をリンクして JiETNG の使用を開始：

```
bind
```

安全な連携用のウェブリンクが提供されます。プライベートチャートのみ対応。

### アカウント連携を解除

SEGA ID を削除し、保存されたすべてのデータを削除：

```
unbind
```

送信後、ボットが確認を求めます。以下を送信して操作を確認してください：

```
unbind confirm
```

:::danger 警告
この操作は取り消せません。すべてのデータが永久に削除されます。
:::

### アカウント設定を変更

連携を解除せずにパスワード・タイムゾーン・言語・Aime 設定を更新：

```
settings
rebind
```

リンクを送信します。Web フォームで現在のアカウント設定を変更できます。SEGA ID は変更できません。プライベートチャートのみ対応。

### スコアを更新

SEGA から最新のスコアを取得：

```
maimai update
```

## 計算機

### 達成率計算機

目標達成率に到達するために必要なパーセンテージを計算：

```
calc <tap> <hold> <slide> [<touch>] <break>
```

例（100 tap、50 hold、30 slide、20 touch、10 break の楽曲）：
```
calc 100 50 30 20 10
```

各ノートタイプの達成率の値を表示します。

## ユーザープロファイル

### ユーザー情報を取得

```
profile
```

## ランキング

### DX Rating ランキング

現在のバージョンのユーザー DX Rating ランキングを表示：

```
rank
ranking
ランキング
```

バージョンを指定することもできます：

```
rank jp
rank intl
```
