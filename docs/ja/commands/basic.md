# 基本コマンド

## アカウント管理

### 連携

```
bind
```

連携リンクを送信します（有効期限：2 分）。プライベートチャットのみ対応。

### 連携解除

```
unbind
```

確認が必要です：

```
unbind confirm
```

:::danger 警告
この操作は取り消せません。すべてのデータが永久に削除されます。
:::

### アカウント設定の変更

```
settings
rebind
```

パスワード・バージョン・タイムゾーン・言語・Aime などを変更するための設定リンクを送信します。SEGA ID は変更できません。プライベートチャットのみ対応。

### スコアを更新

```
maimai update
update
```

レート制限：30 秒以内に最大 2 回。

### 連携情報を確認

```
profile
getme
```

## 計算機

### 達成率計算機

```
calc <tap> <hold> <slide> [<touch>] <break>
```

4 パラメーター（touch なし）または 5 パラメーター（touch あり）：

```
calc 500 100 200 50        # touch なし
calc 500 100 200 30 50     # touch あり
```

### Rating 対照表

```
rc 14.7
RC 14.7
Rc 14.7
```

定数（1.0～15.0、小数点以下 1 桁まで）を入力すると、各達成率に対応する Rating 値を表示します。

## ランキング

```
rank
ranking
ランキング
rank jp       # 日本版ランキング
rank intl     # 海外版ランキング
```

## ランダム楽曲

```
random
random 14        # Lv.14 ランダム（14.0～14.5）
random 14+       # Lv.14+ ランダム（14.6～14.9）
random 14.7      # 定数 14.7 ランダム
```
