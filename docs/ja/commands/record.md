# スコアシステム

Best 50（b50）チャートは JiETNG の基本機能で、美しいビジュアルデザインで最高評価のスコアを表示します。

## Best 50 とは？

「Best 50」システムは Maimai でらっくす の公式ランキング方法で、以下で構成されます：

- **Best 35**：**旧曲**（以前のバージョンの楽曲）でのトップ 35 のハイスコア
- **Best 15**：**新曲**（現在のバージョンの楽曲）でのトップ 15 のハイスコア

あなたの **Maimai でらっくす Rating** は、これら 50 のスコアの合計です。

## コマンド

### 基本 Best チャート

```
b50          # Best 50 チャートを生成
b40          # Best 40 チャートを生成（過去の Rating 計算方式）
b100         # Best 100 チャートを生成
best50       # b50 の代替コマンド
best40       # b40 の代替コマンド
best100      # b100 の代替コマンド
```

### バリエーション

```
best35       # トップ 35 旧曲のみを表示
best15       # トップ 15 新曲のみを表示
ab35         # All Best 35 （楽曲バージョンを無視）
ab50         # All Best 50 （楽曲バージョンを無視）
ab100        # All Best 100（楽曲バージョンを無視）
apb50        # All Perfect Best 50（AP/AP+ スコアのみ）
fdxb50       # Full DX Best 50（FDX/FDX+ スコアのみ）
idlb50       # Ideal Best 50（最高スコアをシミュレート）
```

## 高度な使用方法

### スコアのフィルタリング

b50 出力をカスタマイズするためにフィルターを適用できます：

#### レベルでフィルター

```
b50 -lv 14.7            # 内部定数 14.7 のみ
b50 -lv 14 14.9         # 定数 14.0~14.9（レベル 14 の楽曲すべて）
b50 -lv 15 15.9         # 定数 15.0~15.9（レベル 15 の楽曲すべて）
```

#### Rating でフィルター

```
b50 -ra 200             # Rating 200 のみ（完全一致）
b50 -ra 180 200         # Rating 180-200
```

#### 達成率でフィルター

```
b50 -scr 100.5          # 達成率 100.5%+
b50 -scr 99 100         # 達成率 99%-100%
```

#### でらっくす Score でフィルター

```
b50 -dx 95              # でらっくす score 95%+
b50 -dx 90 95           # でらっくす score 90-95%
```

#### DX 星数でフィルター

```
b50 -star 3             # DX 星数 3 のみ（完全一致）
b50 -star 3 5           # DX 星数 3~5
```

#### バージョンでフィルター

```
b50 -ver buddies                   # Buddies バージョンのみ
b50 -ver splash splash+            # Splash と Splash PLUS バージョン
b50 -ver festival+ buddies         # FESTiVAL PLUS と Buddies バージョン
```

::: tip バージョン名の注意事項
- バージョン名は大文字小文字を区別しません
- PLUS バージョンを示すには `+` を使用します（例：`splash+`）
- 複数のバージョンをスペースで区切って指定できます
:::

#### 難易度でフィルター

```
b50 -diff mas                      # MASTER 難易度のみ
b50 -diff mas rem                  # MASTER と Re:MASTER 難易度
b50 -diff bas adv exp              # BASIC、ADVANCED、EXPERT 難易度
```

::: tip 難易度の略語
- `bas` = BASIC
- `adv` = ADVANCED
- `exp` = EXPERT
- `mas` = MASTER
- `rem` = Re:MASTER
- フルネームも使用できます（例：`basic`、`master`）
- 難易度名は大文字小文字を区別しません
- 複数の難易度をスペースで区切って指定できます
:::

#### 譜面タイプでフィルター

```
b50 -type dx                       # DX 譜面のみ
b50 -type std                      # STD 譜面のみ
```

#### ページ送り

```
b50 -page 2                        # 旧曲 36～70 位、新曲 16～30 位
b100 -page 2                       # 旧曲 71～140 位、新曲 31～60 位
```

### フィルターの組み合わせ

複数のフィルターを組み合わせることができます：

```
b50 -lv 14.7 -scr 100.5                  # 定数 14.7 かつ達成率 100.5%+
b50 -ra 200 -dx 95                       # Rating 200 のみかつ DX score ≥95%
b50 -ver buddies -lv 14 14.9             # Buddies バージョンのレベル 14 楽曲すべて
b50 -ver splash splash+ -scr 100         # Splash/Splash+ かつ達成率 ≥100% の楽曲
b50 -diff mas -lv 14 14.9               # MASTER 難易度のレベル 14 楽曲すべて
b50 -diff mas rem -scr 100.5             # MASTER/Re:MASTER 難易度かつ達成率 100.5%+
b50 -type dx -diff mas                   # DX 譜面の MASTER 難易度
b50 -lv 14 15 -scr 99.5 -dx 90           # 複雑なフィルター
b50 -diff mas -lv 14 14.9 -page 2        # 2 ページ目へ
```

## チャートタイプの説明

### Best 50 (b50)

公式ルールに従った標準ランキングチャート：
- 旧バージョン楽曲のトップ 35
- 新バージョン楽曲のトップ 15
- あなたの実際の でらっくす rating

### Best 100 (b100)

より多くのスコアを表示する拡張版：
- 旧バージョン楽曲のトップ 70
- 新バージョン楽曲のトップ 30

### All Best 50 (ab50)

楽曲バージョンの区別を無視：
- バージョンに関係なくトップ 50 のハイスコア

### All Perfect Best 50 (apb50)

AP 楽曲のみを表示：
- AP（All Perfect）と AP+ スコアのみ
- rating 順にランク付け

### Full DX Best 50 (fdxb50)

FDX 楽曲のみを表示：
- FDX（Full DX）と FDX+ スコアのみ
- rating 順にランク付け

### Ideal Best 50 (idlb50)

理論上の最大 rating：
- すべての楽曲で上位階層のスコアをシミュレート
- 潜在的な rating 成長を表示

## よくある質問

### なぜ私の rating がゲーム内と異なるのですか？

- JiETNG は `maimai update` を実行したときのみ更新されます
- 一部の楽曲定数が標準ではありません

### 一部のスコアが欠けていますか？

最近これらの楽曲をプレイしたか確認してください。古いスコアは以下の場合表示されない可能性があります：
- より良いスコアに置き換えられた
- 楽曲がゲームから削除された
- データ同期の問題（再度 `maimai update` を試してください）


## 定数クエリ

指定した難易度レベルのすべての楽曲を、内部定数（13.0、13.1、13.2 など）でグループ化して表示します。

### コマンド形式

```
13の定数リスト    # 日本語コマンド（定数リスト）
13のレベルリスト  # 日本語コマンド（レベルリスト）
13 level-list   # 英語コマンド
```

### 表示内容

- 左側に内部定数（13.0、13.1、13.2 など）を表示
- 右側に各定数のすべての楽曲カバーを表示
- 上部に総楽曲数の統計を表示
- 定数は高いものから低いものへとソート

### サーバー選択

レベルクエリは連携時に設定されたサーバーバージョン（JP または INTL）を自動的に使用します。

## 難易度評価達成進捗

指定した難易度と評価の達成状況を確認します。例えば、13+ 難易度で SSS+ 評価を達成した譜面の進捗を確認できます。

### コマンド形式

```
13sss+進捗        # 13 難易度 SSS+ 評価の達成状況を確認
13+sss progress   # 13+ 難易度 SSS 評価の達成状況を確認（英語コマンド）
14AP progress 2   # 14 難易度 AP 評価の達成状況を確認（2ページ目）
15fdx+ progress   # 15 難易度 FDX+ 評価の達成状況を確認
```

### サポートされている評価

- **評価ランク**：S、S+、SS、SS+、SSS、SSS+
- **Full Combo**：FC、FC+、AP、AP+
- **Full Sync**：FDX、FDX+

::: tip コマンド説明
- 評価は大文字小文字を区別しません（SSS は sss と同じ）
- 日本語（進捗）と英語（progress）のキーワードをサポート
- コマンドの末尾にページ番号を追加して、より多くの譜面を表示できます
- サポートされている難易度：11、11+、12、12+、13、13+、14、14+、15
:::

### 表示内容

- **完了**：目標評価を達成した譜面（1ページあたり最大 35 個）
- **未完了**：目標評価に達していない譜面（1ページあたり最大 15 個）
- 達成率の高い順にソート
- 最初のページには統計情報を表示：
  - 完了した譜面数
  - 未完了の譜面数
  - 未プレイの譜面数
  - 総譜面数

### 例

```
13sss進捗         # 13 難易度 SSS 評価の進捗を確認（1ページ目）
13sss進捗 2       # 13 難易度 SSS 評価の進捗を確認（2ページ目）
14+ap+ progress   # 14+ 難易度 AP+ 評価の進捗を確認
15fdx progress 3  # 15 難易度 FDX 評価の進捗を確認（3ページ目）
```
