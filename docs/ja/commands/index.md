### サポート機能

| コマンド | エイリアス | 説明 |
|---------|-----------|------|

## アカウント管理

### 連携と表示

| コマンド | エイリアス | 説明 |
|---------|-----------|------|
| `bind` | 無し | SEGAアカウントを連携 |
| `profile` | `getme` | 現在のアカウント連携情報を表示 |
| `unbind` | 無し | アカウント連携を解除 |
| `settings` | `rebind` | 連携を解除せずにアカウント設定（パスワード・タイムゾーン・言語・バージョンなど）を変更 |

### データ更新

| コマンド | エイリアス | 説明 |
|---------|-----------|------|
| `maimai update` | `update` | maimai NETから最新のスコアデータを同期 |

**説明**：
- データ更新コマンドはSEGAアカウント連携が必要です
- 更新は通常数秒で完了します
- 頻度制限：30秒以内に最大2回のリクエスト

## スコア照会

### 標準スコア図

| コマンド | エイリアス | 説明 |
|---------|-----------|------|
| `b50` | `best50` | Best 35（旧譜面）+ Best 15（新譜面） |
| `b40` | `best40` | Best 25（旧譜面）+ Best 15（新譜面）- 過去の Rating 計算方式 |
| `b100` | `best100` | Best 70（旧譜面）+ Best 30（新譜面） |
| `b35` | `best35` | 旧譜面Best 35のみ |
| `b15` | `best15` | 新譜面Best 15のみ |

### 特殊スコア図

| コマンド | エイリアス | 説明 |
|---------|-----------|------|
| `ab35` | `allb35` | 全バージョン混合のBest 35 |
| `ab50` | `allb50` | 全バージョン混合のBest 50 |
| `ab100` | `allb100` | 全バージョン混合のBest 100 |
| `apb50` | `ap50` | AP/AP+のみのBest 50 |
| `fdxb50` | `fdx50` | FDX/FDX+のみのBest 50 |
| `rct50` | `r50`, `recent50` | 最近50回のプレイ記録 |
| `idealb50` | `idlb50` | 理想スコアBest 50 |

### 高度なフィルター

すべてのスコア図コマンドで以下のフィルターパラメータを使用できます：

| パラメータ | 説明 | 例 |
|-----------|------|-----|
| `-lv [値] [max]` | 譜面定数で絞り込み。値1つ = 完全一致；値2つ = 範囲指定 | `b50 -lv 13.2 13.8` または `b50 -lv 13.7` |
| `-ra [値] [max]` | Ratingで絞り込み。値1つ = 完全一致；値2つ = 範囲指定 | `b50 -ra 301 312` または `b50 -ra 301` |
| `-star [値] [max]` | DX星数で絞り込み。値1つ = 完全一致；値2つ = 範囲指定 | `b50 -star 3 5` または `b50 -star 3` |
| `-scr [min] [max]` | 達成率で絞り込み（max省略可、省略時は上限なし） | `b50 -scr 100.3 100.8` または `b50 -scr 100.3` |
| `-dx [min] [max]` | DXスコアのパーセンテージで絞り込み（max省略可、省略時は上限なし） | `b50 -dx 92 95` または `b50 -dx 92` |

**注意**：パラメータの種類によってフィルター動作が異なります：
- `-lv 13.7` は譜面定数 = 13.7（完全一致）を意味します。範囲指定は `-lv 13.5 14.0` のように2つの値を使用
- `-ra 301` は Rating = 301（完全一致）を意味します。範囲指定は `-ra 301 312` のように2つの値を使用
- `-star 3` は DX星数 = 3（完全一致）を意味します。範囲指定は `-star 3 5` のように2つの値を使用
- `-scr 100.3` は達成率 ≥100.3%（上限なし）を意味します
- `-dx 92` は DXスコア ≥92%（上限なし）を意味します

#### フィルター組み合わせ例

```
b50 -lv 13.2 13.8                    # 譜面定数13.2〜13.8のB50
b50 -lv 13.7                         # 譜面定数が正確に13.7のB50
b50 -ra 301 312                      # Rating 301〜312のB50
b50 -ra 301                          # Rating が正確に301のB50
b50 -star 3 5                        # DX星数3〜5のB50
b50 -star 3                          # DX星数が正確に3のB50
b50 -scr 100.3 100.8                 # 達成率100.3%〜100.8%のB50
b50 -scr 100.3                       # 達成率 ≥100.3%のB50（上限なし）
b50 -dx 92 95                        # DXスコア92%〜95%のB50
b50 -dx 92                           # DXスコア ≥92%のB50（上限なし）
b50 -lv 13.2 13.8 -scr 100.0         # 譜面定数13.2〜13.8かつ達成率 ≥100%のB50
b100 -lv 13.0 14.9 -dx 92 95         # 譜面定数13.0〜14.9かつDX 92%〜95%のB100
idealb50 -lv 13.5 14.0               # 譜面定数13.5〜14.0の理想スコアB50
```

## 楽曲検索

### 楽曲情報

| コマンド形式 | エイリアス | 説明 | 例 |
|------------|-----------|------|-----|
| `[曲名]ってどんな曲` | `[曲名]info`, `[曲名]song-info` | 楽曲の詳細情報を検索 | `ヒバナってどんな曲` |
| `[曲名]のレコード` | `[曲名]record`, `[曲名]song-record` | 個人スコアを表示 | `ヒバナのレコード` |

### レベル別スコアリスト & 定数リスト

| コマンド形式 | エイリアス | 説明 | 例 |
|------------|-----------|------|-----|
| `[レベル]のレコードリスト (ページ)` | `[レベル]record-list (ページ)`, `[レベル]records (ページ)` | 指定レベルのすべてのスコアを表示 | `13のレコードリスト` |
| `[定数]のレコードリスト (ページ)` | `[定数]record-list (ページ)`, `[定数]records (ページ)` | 指定定数のすべてのスコアを表示 | `14.5のレコードリスト` |

**説明**：
- **レベルリスト**：整数（1〜15）を入力してそのレベルのすべての譜面を表示
  - 例：`13のレコードリスト` - すべての Lv.13 譜面のスコアを表示
- **定数リスト**：小数を入力して指定定数のすべての譜面を表示
  - 例：`14.5のレコードリスト` - すべての定数 14.5 の譜面スコアを表示
  - 例：`13.7のレコードリスト` - すべての定数 13.7 の譜面スコアを表示
- 1ページ最大 50 件（旧バージョン最大 35 件 + 新バージョン最大 15 件）、ページパラメータで移動可能
- Rating降順で自動ソート

## バージョン達成

### 称号達成状況

**コマンド形式**：`[バージョン姓名框]の達成状況`

**エイリアス**：`の達成状況`の代わりに`achievement-list`または`achievement`を使用できます

| 称号タイプ | コマンド例 | 説明 |
|----------|-----------|------|
| 極（Extreme） | `宴極の達成状況` | 「宴極」称号の達成状況を表示 |
| 将（Master） | `双将の達成状況` | 「双将」称号の達成状況を表示 |
| 神（God） | `鏡神の達成状況` | 「鏡神」称号の達成状況を表示 |
| 舞舞（Dancer） | `彩舞舞の達成状況` | 「彩舞舞」称号の達成状況を表示 |

**その他の例**：
```
宴極の達成状況                # 宴 極
双将の達成状況                # 双 将
鏡神の達成状況                # 鏡 神
彩舞舞の達成状況              # 彩 舞舞
真極の達成状況                # 真 極
真将の達成状況                # 真 将
真神の達成状況                # 真 神
真舞舞の達成状況              # 真 舞舞
```

**英語エイリアス例**：
```
宴極achievement-list            # 宴極の達成状況と同じ
双将achievement                 # 双将の達成状況と同じ
```

## フレンド機能

### フレンド管理

| コマンド | エイリアス | 説明 |
|---------|-----------|------|
| `friend list` | `friends` | ゲーム内フレンドリストを表示 |
| `friend-rcd [フレンドコード] [タイプ?] [フィルター?]` | 無し | フレンドの成績チャートを表示 |

**例**：
```
friend list                                   # フレンドリストを表示
friend-rcd 1234567890123456                   # フレンドの B50 を表示（デフォルト）
friend-rcd 1234567890123456 b100              # フレンドの B100 を表示
friend-rcd 1234567890123456 b50 -lv 14.7     # フレンドの B50（定数 14.7）を表示
```

**説明**：
- SEGAアカウント連携が必要です
- `[タイプ]` はすべての B 系コマンド（b50、b100、ab50 など）をサポートし、デフォルトは b50 です
- `[フィルター]` は b50 と同じフィルターパラメーター（-lv、-ra、-scr など）をサポートします
- プライベートチャートのみ対応、グループチャットでは使用不可

## ユーティリティコマンド

### Rating計算

| コマンド | 説明 | 例 |
|---------|------|-----|
| `rc [定数]` | 指定定数のRating対照表を表示 | `rc 13.2` |

### スコア計算

| コマンド | 説明 | 例 |
|---------|------|-----|
| `calc [tap] [hold] [slide] (touch) [break]` | ノーツスコア計算 | `calc 500 100 200 50 50` |

**説明**：
- 計算機は各種ミス（Great/Good/Miss）に対応する達成率を表示します
- 4パラメータ（touchなし）と5パラメータ（touchあり）の両方の形式をサポートしています

### ランダム選曲

| コマンド | 説明 | 例 |
|---------|------|-----|
| `random (レベル/定数)` | ランダムに楽曲を選択 | `random 14` |

### 位置情報サービス

| 機能 | 説明 |
|------|------|
| 位置情報を送信 | 近くのmaimai設置店舗を検索（最大4件表示） |

**説明**：
- LINEで「+」ボタンをタップし、「位置情報」を選択
- 現在地または任意の位置を送信
- Botは近くのmaimai設置店舗情報（名前、住所、距離、地図リンク）を返信します

### ランキング

| コマンド | エイリアス | 説明 |
|---------|-----------|------|
| `rank` | `ranking`, `ランキング` | 現在のバージョンのユーザー DX Rating ランキングを表示 |
| `rank jp` | `ranking jp`, `ランキング jp` | 日本版 DX Rating ランキングを表示 |
| `rank intl` | `ranking intl`, `ランキング intl` | 海外版 DX Rating ランキングを表示 |

**説明**：
- 同バージョンの JiETNG ユーザーの DX Rating ランキングを表示
- `jp` または `intl` を指定して特定バージョンのランキングを表示できます

## @メンション機能

グループチャットで登録済みの JiETNG ユーザーをメンション（@）すると、そのユーザーのデータを表示できます。

**使い方**：ユーザーをメンション + コマンド（メンションはコマンドのどこでも使用可能）

**例**：
```
@フレンド b50              # フレンドの B50 を表示
@フレンド profile          # フレンドのアカウント情報を表示
@フレンド 14 record-list   # フレンドの Lv14 成績リストを表示
```

**説明**：
- メンションされたユーザーが JiETNG に登録していない場合は、自分のデータが表示されます
- 成績関連のすべてのコマンドをサポート（b50、b100、record-list、progress など）
